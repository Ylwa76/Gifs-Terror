GIFS_TERROR 

**GIFS_TERROR** — это интерактивная песочница для хаотичного вывода GIF-анимаций на экран. Программа создаёт окно в ностальгическом стиле Windows XP , заполняет его случайными гифками из вашей папки, добавляет фоновую музыку и позволяет взаимодействовать с ними с помощью мыши и клавиатуры.

##  Основные возможности

* **Кастомный интерфейс:** Окно оформлено в стиле Windows XP (кастомный заголовок, кнопки, тени).
* **Умное кэширование:** Размеры гифок кэшируются в `gif_cache.json` для мгновенного запуска и экономии ресурсов.
* **Масштабирование:** Размер гифок автоматически подстраивается под размер окна.
* **Фоновая музыка:** Случайный трек из папки `music` запускается со случайной секунды. При окончании включается следующий трек.
* **Окно настроек (GUI):** Встроенное окно настроек (кнопка ⚙ в заголовке) позволяет менять параметры на лету без правки JSON-файлов.
* **Множество эффектов:** Более 10 визуальных эффектов (вращение, гравитация, пульсация, зигзаг, изменение цвета и др.).
* **Оптимизация:** Встроенная защита от переполнения системных таймеров Windows и утечек памяти при пересоздании гифок.

 Управление

Управление заточено под быстрое и интуитивное взаимодействие:

| Действие | Результат |
| :--- | :--- |
| **ЛКМ (Левая кнопка)** | Вешает случайный эффект на гифку (повторный клик меняет эффект) |
| **ПКМ (Правая кнопка)** | Вешает случайный набор эффектов на *все* гифки сразу |
| **Средняя кнопка (Колесико)** | Плавно удаляет гифку с экрана |
| **Alt + ЛКМ** | Схватить и перетащить гифку (поднимает её на передний план) |
| **Alt + ПКМ** | Собрать все гифки в кучу за курсором, а при отпускании — «выстрелить» ими в направлении движения мыши |
| **Alt + Колесико** | Изменить размер гифки |
| **Alt + ЛКМ + Колесико** | Вращать гифку |
| **Пробел** | Пересоздать все гифки  |

# Настройки (config.json)

Хотя настройки можно менять через встроенное окно, они хранятся в файле `config.json`. Основные параметры:

* `gifs_min` / `gifs_max` — минимальное и максимальное количество гифок на экране.
* `music_enabled` / `music_volume` — включение музыки и её громкость.
* `gif_speed` — скорость воспроизведения анимации (в процентах).
